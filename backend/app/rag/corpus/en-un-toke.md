## Pagos y envíos

La tienda es WordPress con WooCommerce. Mercado Pago cobra y Correo Argentino envía. No hay una API propia de checkout: el flujo documentado usa esos plugins.

## Campañas

Meta Pixel y la API de Conversiones miden las campañas. La ficha no describe un backend separado ni una cola de pedidos. El sitio publicado es enuntoke.com.
