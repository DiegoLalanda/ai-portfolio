# Reclamos, forma de la API

project_id: proj-claims-api
lang: es

## Contrato HTTP

La API de reclamos de la concesionaria es REST con Node.js, Express y PostgreSQL vía Sequelize. La autenticación es JWT. Swagger documenta los endpoints para que un frontend se integre sin leer el código.

## Límite del proyecto

Es un trabajo académico de backend. No incluye el panel visual ni una app móvil. La ficha no describe colas ni workers: el diseño documentado es request y response sobre HTTP.
